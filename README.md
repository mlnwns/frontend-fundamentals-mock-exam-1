# 적금 계산기

사용자 입력에 따라 적금 상품을 필터링하고, 예상 수익을 계산해주는 애플리케이션입니다.

## Getting started

```sh
yarn install
yarn dev
```

## 주요 기능

### 구현된 기능

#### 1. **적금 상품 필터링**

- 사용자가 입력한 월 납입액과 저축 기간에 맞는 상품만 표시
- 초기 로드 시 12개월을 기본값으로 조건에 맞는 상품 표시
- 월 납입액 입력 시 500ms 디바운싱 적용으로 불필요한 필터링 연산 감소

#### 2. **상품 선택 기능**

- 적금 상품 목록에서 원하는 상품 선택 (한 번에 1개만 선택 가능)
- 선택된 상품은 우측에 초록 체크 아이콘으로 표시
- 필터링 조건이 변경되어 선택된 상품이 제외되면 자동으로 선택 해제

#### 3. **입력 폼 포맷팅**

- 월 납입액, 목표 금액 입력 시 쉼표(`,`) 자동 추가
- 숫자만 입력 가능하며, 입력 중에도 실시간 포맷팅

#### 4. **계산 결과 탭**

선택한 적금 상품에 대해 다음 항목을 자동 계산:

- **예상 수익 금액**: `월 납입액 × 저축 기간 × (1 + 연이자율 × 0.5)`
- **목표 금액과의 차이**: `목표 금액 - 예상 수익 금액`
- **추천 월 납입 금액**: `목표 금액 ÷ (저축 기간 × (1 + 연이자율 × 0.5))`

#### 5. **추천 상품 목록**

- 필터링된 상품 중 연 이자율이 가장 높은 2개 상품 자동 추출
- 선택된 상품이 있으면 추천 목록에서도 체크 아이콘 표시

#### 6. **TanStack Query 연동**

- 적금 상품 데이터를 `useQuery`로 관리
- 자동 캐싱, 백그라운드 리페칭 등 데이터 관리 최적화

## 사용자 경험 개선 사항

### 구현된 UX 개선

1. **초기값 설정**: 페이지 로드 시 바로 상품을 볼 수 있도록 기본값 설정
2. **자동 선택 해제**: 필터링으로 선택 상품이 제외되면 자동 해제로 혼란 방지
3. **디바운싱**: 입력 중 불필요한 필터링 연산 감소로 UI 반응성 개선
4. **숫자 포맷팅**: 입력 중 실시간 쉼표 추가로 금액 가독성 향상
5. **조건 없음 처리**: 조건에 맞는 상품이 없을 때 명확한 메시지 표시

### 개선 가능 사항

#### 1. **로딩 및 에러 상태 처리**

- 상품 로딩 중 스켈레톤 UI 표시
- API 에러 시 재시도 버튼 제공
- 네트워크 오류 메시지 표시

#### 2. **입력 값 검증**

- 월 납입액이 모든 상품의 범위를 벗어나면 경고
- 목표 금액을 입력하지 않고 계산 결과 탭을 클릭하면 경고

#### 3. **반응형 UI 개선**

- 탭 선택 후 화면 크기 변경 시 선택 안내 바 위치 조절

#### 4. **접근성 개선**

- ARIA 레이블 추가
- 키보드 네비게이션 지원
- 스크린 리더 지원
